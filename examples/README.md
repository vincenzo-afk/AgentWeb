# Examples

Runnable, end-to-end examples showing AgentWeb solving real workflows. Each folder contains a focused example with its own README.

| Example | Demonstrates |
|---|---|
| [research-agent](research-agent/) | Multi-step autonomous research using the [Agent APIs](../docs/concepts/agents.md) |
| [monitoring-agent](monitoring-agent/) | Generic competitor/page monitoring with `internet.observe()` |
| [company-analysis](company-analysis/) | Deep company research with citations, using `dive` mode |
| [product-comparison](product-comparison/) | Comparing products across price and specs |
| [visa-slot-tracker](visa-slot-tracker/) | High-frequency slot/availability monitoring |
| [docs-watcher](docs-watcher/) | Watching documentation/release notes for changes |
| [browser-flow](browser-flow/) | Explicit multi-step browser interaction |
| [custom-skill](custom-skill/) | Defining and using a custom [Internet Skill](../docs/concepts/internet-skills.md) |

See [docs/getting-started](../docs/getting-started/index.md) before diving into these if you're new to AgentWeb.
