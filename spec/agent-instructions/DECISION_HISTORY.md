# Decision History

Formal log of decisions made during implementation that weren't fully pre-specified — distinct from [../decisions/ARCHITECTURE_DECISIONS.md](../decisions/ARCHITECTURE_DECISIONS.md) (which are the pre-planned ADRs). This log captures decisions made *during* the build, often by an implementing agent, that should be reviewed and potentially promoted into a formal ADR.

## Format

```
## [YYYY-MM-DD] <decision title>
Trigger: <what forced this decision — spec ambiguity, unexpected constraint, etc.>
Options considered: <brief list>
Decision: <what was chosen>
Rationale: <why, referencing MANIFESTO.md principles or existing ADRs where applicable>
Status: <proposed | accepted | needs human review>
```
