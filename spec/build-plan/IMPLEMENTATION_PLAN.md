# Implementation Plan

## Phase 0 (MVP) build targets
Search, Extractor, Parser, Normalizer, Ranking (basic), Synthesis (basic), Memory (snapshot/hash/reuse), Monitor (basic), Alerting, API tier for `solve`/`observe`. Matches [docs/roadmap.md](../../docs/roadmap.md) Phase 0 scope.

## Phase 1 build targets
Crawler, Browser, Connector, full retrieval-mode support, webhook depth improvements.

## Phase 2 build targets
Graph, Vector Store (entity resolution), graph-aware Synthesis.

## Phase 3 build targets
Planner/Router upgrade for agent-native plan/execute separation, Skills registry, Agent API endpoints.

## Phase 4 build targets
Event-driven workflow triggers beyond simple webhook alerts.

See [TASK_BREAKDOWN.md](TASK_BREAKDOWN.md) for task-level detail within each phase and [MILESTONES.md](MILESTONES.md) for exit criteria per phase.
