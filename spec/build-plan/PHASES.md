# Phases

Maps [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) build targets onto [docs/roadmap.md](../../docs/roadmap.md) product phases:

| Phase | Product goal | Key build targets |
|---|---|---|
| 0 — MVP | Prove outcome-first orchestration beats fragmented tooling for one workflow | Search, Extract, Memory (basic), Ranking (basic), Synthesis (basic), Monitor, Alerting |
| 1 — Depth & Modes | Legible speed/depth tradeoff, richer extraction | Crawler, Browser, Connector, full retrieval modes |
| 2 — Memory & Graph | Relationship-aware queries | Graph, Vector Store, graph-aware Synthesis |
| 3 — Agent-Native Platform | Serve autonomous agents directly | Skills registry, Planner/Router agent-mode, Agent APIs |
| 4 — Event-Driven Internet | Proactive, not just reactive | Workflow triggers beyond webhook alerts |

See [MILESTONES.md](MILESTONES.md) for phase exit criteria.
