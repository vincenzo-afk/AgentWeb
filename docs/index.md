# AgentWeb Documentation

Welcome to the AgentWeb documentation. Use this index to find what you need.

- **New here?** Start with [Getting Started](getting-started/index.md).
- **Want the "why"?** Read [Vision](vision.md) and [Concepts](concepts/index.md).
- **Building an integration?** Go to [API Reference](api/index.md) or [SDKs](sdk/index.md).
- **Curious how it works internally?** See [Core Systems](core/index.md) and [Architecture](architecture.md).
- **Task-oriented how-tos:** [Guides](guides/index.md).
- **Deploying or operating AgentWeb:** [Operations](operations/index.md) and [Security](security/index.md).
- **Deeper research and strategy context:** [Research](research/index.md).

| Section | Audience | Purpose |
