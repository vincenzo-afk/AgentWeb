# Future Directions

Longer-horizon ideas beyond the near-term [roadmap.md](../roadmap.md).

- **Full event-driven internet infrastructure** — internet changes as first-class triggers driving automated downstream workflows, not just alerts. See [concepts/event-driven-internet.md](../concepts/event-driven-internet.md).
- **Self-improving planner** — plans that succeed for a task class are automatically promoted into reusable [Internet Skills](../concepts/internet-skills.md), reducing the need for manual skill authoring.
- **Cross-organization graph intelligence** (with appropriate privacy boundaries) — shared entity resolution across customers to improve graph quality without leaking any customer's private task data.
- **Deeper agent supervision tooling** — richer plan-approval and intervention flows for autonomous agents built on the [Agent APIs](../concepts/agents.md).
- **Domain-specific verticals** — packaged skill libraries for specific industries (ecommerce monitoring, compliance research, competitive intelligence) built on the same core platform.

These are directional, not committed; see [roadmap.md](../roadmap.md) for what's actually scheduled.
