# User Segments

AgentWeb serves a broader set of segments than "AI apps that need search," consistent with its positioning as an Internet Intelligence Platform (see [concepts/internet-intelligence.md](../concepts/internet-intelligence.md)).

| Segment | Representative use cases |
|---|---|
| AI/agent developers | Grounding model responses, multi-step autonomous research, tool routing, citation-backed generation |
| Product/developer teams | Unified web access, structured extraction, browser-backed workflows, change monitoring |
| Business/operations teams | Competitor monitoring, price tracking, stock/availability alerts, market intelligence |
| Research/analyst teams | Company research, source-grounded reports, funding/release/ecosystem tracking |
| Consumer-facing/automation builders | Visa slot tracking, shopping monitors, release-note and policy-update alerts |
| Compliance/security teams | Inspectable, auditable evidence trails for decisions that require justification |

Each segment maps to concrete examples under [examples/](../../examples/README.md) and use cases catalogued in [vision.md](../vision.md).
