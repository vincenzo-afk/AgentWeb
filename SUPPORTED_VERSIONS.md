# Supported Versions

| Version | API status | Security fixes |
|---|---|---|
| v1 (current) | Fully supported | Yes |
| v0 (pre-release) | Deprecated | No |

Only the current major API version receives new features. The prior major version receives security fixes for a minimum notice period after a new major version ships; see [docs/api/versioning.md](docs/api/versioning.md) for the deprecation policy and [SECURITY.md](SECURITY.md) for how to report a vulnerability.

## SDK support

| SDK | Supported | Notes |
|---|---|---|
| JavaScript/TypeScript | Yes | Tracks API v1 |
| Python | Yes | Tracks API v1 |
| REST (direct) | Yes | Always current |
